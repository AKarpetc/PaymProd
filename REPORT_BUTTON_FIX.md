# ✅ Кнопка генерации отчета исправлена!

## 🐛 Проблема

Кнопка "Генерация отчета" в сайдбаре открывала **пустую страницу отчетов** без данных меню.

## 🔧 Что было исправлено

### 1. **Убрана кнопка из сайдбара**
Кнопка "Отчеты" удалена из бокового меню, так как отчет должен генерироваться для **конкретного открытого меню**, а не как отдельный раздел.

### 2. **Добавлена кнопка на главной странице**
Новая оранжевая кнопка **"Генерация отчета"** добавлена на панель быстрых действий страницы меню:

```xml
<Button Style="{StaticResource MaterialDesignRaisedButton}" 
        Click="GenerateReport_Click" Margin="5"
        Background="#FF9800">
    <StackPanel Orientation="Horizontal">
        <materialDesign:PackIcon Kind="FileDocument"/>
        <TextBlock Text="Генерация отчета"/>
    </StackPanel>
</Button>
```

### 3. **Реализована логика генерации**
Добавлен новый метод в `MenuPage.xaml.cs`:

```csharp
private void GenerateReport_Click(object sender, RoutedEventArgs e)
{
    // Проверяем, что есть открытое меню с блюдами
    if (!_currentMenuId.HasValue || _currentMenuDelicates.Count == 0)
    {
        MessageBox.Show("Нет данных для отчета!\n\nСоздайте меню и добавьте блюда.");
        return;
    }

    // Собираем информацию о банкете
    var banquetInfo = new List<string>
    {
        BanquetNameTextBox.Text,
        PeopleCountTextBox.Text,
        BanquetDatePicker.SelectedDate?.ToString() ?? DateTime.Now.ToString(),
        DescriptionTextBox.Text
    };

    // Создаем страницу отчета с данными текущего меню
    var reportPage = new ReportPage
    {
        MenuDelicates = _currentMenuDelicates,
        BanquetInfo = banquetInfo
    };

    // Навигируем к странице отчета
    Services.NavigationService.Instance.NavigateTo(reportPage);
}
```

## 🎯 Как теперь использовать

### Шаг 1: Создайте или откройте меню
1. Введите название банкета
2. Укажите количество человек
3. Выберите дату
4. Нажмите **"Перейти к заполнению"** или откройте существующее меню

### Шаг 2: Добавьте блюда
1. Выберите тип блюда (Все, Закуски, Горячее и т.д.)
2. Дважды кликните на блюдо из списка доступных
3. Укажите количество порций

### Шаг 3: Сгенерируйте отчет
1. Нажмите оранжевую кнопку **"📄 Генерация отчета"** в верхней панели
2. Откроется страница отчета с:
   - Подробным списком всех блюд по типам
   - Составом каждого блюда
   - Сводной таблицей продуктов
   - Кнопками экспорта в Excel

## ⚠️ Важные моменты

### ✅ Работает только с открытым меню
Кнопка проверяет:
- Есть ли открытое меню (`_currentMenuId`)
- Добавлены ли блюда (`_currentMenuDelicates.Count > 0`)

Если условия не выполнены, показывается предупреждение:
```
Нет данных для отчета!

Создайте меню и добавьте блюда.
```

### ✅ Передача данных
ReportPage получает данные через свойства:
- `MenuDelicates` - список блюд с количеством
- `BanquetInfo` - информация о банкете (название, дата, количество людей, описание)

### ✅ Навигация
После генерации отчета:
- Страница отчета открывается в основной области
- Кнопка **"← Назад"** в верхней панели позволяет вернуться к меню
- История навигации сохраняется
