## 🚀 Как использовать

### Работа с текущим меню:

1. **Открыть текущее меню:**
   - Кликните **📝 Текущее меню** в сайдбаре

2. **Создать новый банкет:**
   - Заполните форму в нижней части:
     - Название банкета
     - Количество человек
     - Дата
     - Описание
   - Нажмите **▶ Начать**

3. **Добавить блюда:**
   - В нижней панели найдите нужное блюдо
   - Введите количество порций в поле
   - **Дважды кликните** по карточке блюда
   - Блюдо добавится в список **ВВЕРХУ**

4. **Редактировать количество:**
   - В верхней таблице измените количество порций
   - Нажмите **💾 Сохранить изменения**

5. **Удалить блюдо:**
   - Нажмите красную кнопку **🗑️** в строке блюда

6. **Генерировать отчет:**
   - Нажмите **📊 Генерация отчета**
   - Откроется страница с расчетом продуктов

7. **Начать новое меню:**
   - Нажмите **➕ Новое меню**
   - Текущее меню закроется
   - Форма очистится

### Работа с сохраненными меню:

1. **Посмотреть все банкеты:**
   - Кликните **💾 Сохраненные меню** в сайдбаре
   - Откроется список всех банкетов

2. **Открыть меню для редактирования:**
   - Нажмите синюю кнопку **✏️** в строке меню
   - Откроется страница "Текущее меню" с этим банкетом

3. **Удалить меню:**
   - Нажмите красную кнопку **🗑️** в строке меню
   - Подтвердите удаление
