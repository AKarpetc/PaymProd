## PaymProd — проекты решения

В этом репозитории несколько связанных проектов, работающих с системой управления меню банкетов.

- **`PaymProdNet9`** — основное WPF‑приложение для работы с меню банкетов, справочниками и отчетами.
- **`PaymProdDbTool`** — вспомогательное WPF‑приложение для администрирования базы данных SQLite.
- **`S3UploadTool`** — консольный инструмент для загрузки установщиков и стартовой базы в S3‑совместимое хранилище (Yandex Cloud).
- **`Installer`** — скрипты сборки инсталлятора (Inno Setup) и файлы авто‑обновления.

Подробная документация по основному приложению `PaymProdNet9` находится в:

- [PaymProdNet9/docs/README.md](PaymProdNet9/docs/README.md)

Рекомендуется начать именно с этого файла — там есть ссылки на:

- общий обзор приложения;
- формы меню и банкетов;
- справочники и единицы измерения;
- отчеты по меню и по товарам;
- управление базой данных и обновлениями.

### Дополнительные проекты

- **`PaymProdDbTool`**  
  Отдельное окно для работы напрямую с файлом `MenuCalc.db`:
  - выбор пути к базе (по умолчанию `%LOCALAPPDATA%\PaymProdNet9\MenuCalc.db`);
  - просмотр таблиц и данных;
  - массовая смена флагов `Priz_menu` / `Avtomat` у продуктов;
  - скачивание стартовой базы (через тот же сервис, что использует основное приложение);
  - сохранение базы «как…» (быстрый экспорт в отдельный файл).

- **`S3UploadTool`**  
  Консольный инструмент для публикации файлов обновления в S3‑совместимое хранилище:
  - читает конфигурацию из `s3config.json` (endpoint, ключи, bucket);
  - берет файлы из `Installer\auto_update_files` (по умолчанию);
  - загружает только новые/измененные файлы (по дате изменения);
  - используется для выкладки `PaymProdNet9_Setup.exe`, `MenuCalc.start.db`, `update-info.json` и т.п.

Подробнее о настройке и запуске `S3UploadTool` смотрите в [S3UploadTool/README.md](S3UploadTool/README.md).
