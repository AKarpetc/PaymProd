## 🚀 Как использовать

### Работа с блюдами

1. **Открыть справочник блюд:**
   - Кликните на **🍽️ Блюда** в сайдбаре

2. **Создать новое блюдо:**
   - Нажмите зеленую кнопку **"➕ Создать новое блюдо"**
   - Заполните:
     - Название
     - Тип блюда
     - Вес порции (опционально)
     - Количество порций
   - Нажмите **"💾 Сохранить блюдо"**

3. **Добавить состав:**
   - После создания блюда (или выбора существующего)
   - В левой панели найдите нужный продукт
   - Нажмите **→** чтобы добавить в состав
   - В таблице состава укажите вес каждого продукта
   - Нажмите **"💾 Сохранить блюдо"**

4. **Редактировать блюдо:**
   - Кликните на блюдо в таблице
   - Измените нужные поля
   - Нажмите **"💾 Сохранить блюдо"**

5. **Удалить блюдо:**
   - Нажмите красную кнопку **🗑️** в строке блюда
   - Подтвердите удаление

### Работа с продуктами

1. **Открыть справочник продуктов:**
   - Кликните на **🛒 Продукты** в сайдбаре

2. **Создать новый продукт:**
   - Нажмите зеленую кнопку **"➕ Создать новый продукт"**
   - Заполните:
     - Название
     - Тип продукта
     - Единица измерения
   - Нажмите **"💾 Сохранить продукт"**

3. **Редактировать продукт:**
   - Кликните на продукт в таблице
   - Измените нужные поля
   - Нажмите **"💾 Сохранить продукт"**

4. **Удалить продукт:**
   - Нажмите красную кнопку **🗑️** в строке продукта
   - Подтвердите удаление

private void NavigateToDelicates_Click(object sender, RoutedEventArgs e)
{
    SetActiveButton(sender as Button);
    PageTitle.Text = "Справочник блюд";
    NavigationService.Instance.NavigateTo<DelicatesPage>();
}

private void NavigateToProducts_Click(object sender, RoutedEventArgs e)
{
    SetActiveButton(sender as Button);
    PageTitle.Text = "Справочник продуктов";
    NavigationService.Instance.NavigateTo<ProductsPage>();
}
