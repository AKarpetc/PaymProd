🚀 ВАРИАНТ 1 (самый простой):
   
   Откройте папку PaymProdNet9 и запустите:
   ▶️  run.bat

🚀 ВАРИАНТ 2 (через командную строку):
   
   cd PaymProdNet9
   dotnet run

🚀 ВАРИАНТ 3 (создать исполняемый файл):
   
   cd PaymProdNet9
   dotnet publish -c Release -r win-x64 --self-contained
   
   Готовый exe будет в папке:
   bin\Release\net9.0-windows\win-x64\publish\PaymProdNet9.exe
