# Руководство по отладке

## Просмотр логов

### В Visual Studio / Rider
1. Откройте окно **Output** (Выходные данные)
2. В выпадающем списке выберите **Debug**
3. Все логи будут отображаться там

### В файле
Логи сохраняются в:
```
%LocalAppData%\PaymProdNet9\Logs\PaymProd_YYYYMMDD.log
```

Например:
```
C:\Users\ВашеИмя\AppData\Local\PaymProdNet9\Logs\PaymProd_20251125.log
```

## Что логируется

### SQL-запросы (только в Debug режиме)
Все SQL-запросы с параметрами автоматически логируются при использовании extension методов:
- `ExecuteNonQueryWithLog()`
- `ExecuteScalarWithLog()`
- `ExecuteReaderWithLog()`

### Ошибки
Все ошибки автоматически логируются с полным стеком вызовов:
- Необработанные исключения
- Ошибки в UI потоке
- Ошибки в асинхронных задачах
- Ошибки при работе с БД

## Исправление ошибки FOREIGN KEY

Ошибка "FOREIGN KEY constraint failed" исправлена:
- Для продуктов (отрицательные ID) проверка внешних ключей отключается
- Для обычных блюд проверяется существование блюда перед добавлением
- Все операции выполняются в транзакциях

## Проверка работы

1. Запустите приложение в **Debug режиме**
2. Откройте окно **Output** в IDE
3. Попробуйте добавить блюдо
4. Проверьте логи - должны быть видны:
   - SQL-запросы с параметрами
   - Отладочные сообщения
   - Ошибки (если есть)

## Если логи не видны

1. Убедитесь, что запускаете в **Debug режиме** (не Release)
2. Проверьте файл логов в `%LocalAppData%\PaymProdNet9\Logs\`
3. Проверьте окно **Output** в IDE (не консоль)
