## Управление базой данных и обновления

Этот документ описывает:

- расположение и инициализацию базы данных SQLite;
- резервное копирование и восстановление;
- загрузку стартовой базы;
- окно загрузки обновлений.

---

### Расположение и инициализация базы данных

База данных `MenuCalc.db` **всегда** хранится в каталоге AppData текущего пользователя:

```csharp
var appDataDir = Path.Combine(
    Environment.GetFolderPath(Environment.SpecialFolder.LocalApplicationData),
    "PaymProdNet9");
var dbPath = Path.Combine(appDataDir, "MenuCalc.db");
```

Это исключает проблемы с правами доступа при установке в `C:\Program Files`.

#### `App.xaml.cs`

В методе `OnStartup`:

1. Показывается splash‑окно.
2. Определяется путь к базе данных (только AppData).
3. При отсутствии файла:
    - вызывается `UpdateService.TryDownloadStartDatabaseAsync(dbPath, ...)` для загрузки стартовой базы с сервера;
    - при неудаче пользователь видит сообщение об ошибке.
4. Затем вызывается:

```csharp
Data.DatabaseHelper.InitializeDatabase(dbPath);
```

#### `DatabaseHelper`

Класс отвечает за:

- формирование строки подключения `ConnectionString` (только AppData);
- создание таблиц и применение миграций;
- инициализацию базовых справочников (`Mera`, `Produkt_Type`, `Type_Del`).

При первом запуске:

- автоматически добавляются базовые единицы измерения (`г`, `кг`, `л`, `мл`, `шт`, `порция`);
- базовые типы продуктов и блюд (овощи, мясо, салаты и т.п.).

### `DatabaseManagerPage` — страница управления БД

Доступна из `MainNavigationWindow` → «Управление базой данных».

Основные функции:

1. **Просмотр текущего пути к базе и информации о ней** (`LoadCurrentDatabaseInfo`).
2. **Создание новой «чистой» базы**:
    - текущая база переносится в резервную копию (через `DatabaseBackupHelper`);
    - создается новый файл `MenuCalc.db`;
    - рекомендуется перезапустить приложение.
3. **Загрузка стартовой базы данных**:

```csharp
var downloaded = await UpdateService.TryDownloadStartDatabaseAsync(
    currentPath,
    window,
    replaceExisting: true,
    silentSuccess: false);
```

- файл скачивается с сервера (адрес задается в `UpdateService.UpdateInfoUrl`);
- при успехе текущая база заменяется скачанной;
- пользователь информируется о необходимости перезапуска.

4. **Отправка логов на S3**:
    - ищется последняя запись в `%LOCALAPPDATA%\PaymProdNet9\Logs\PaymProd_*.log`;
    - файл загружается в хранилище (через `S3UploadService`);
    - отображается результат (успех/ошибка).

### `DatabaseManagerWindow` — классическое окно управления БД

Старый интерфейс для управления базой (используется в режиме отладки и в старом меню).

Возможности:

1. **Просмотр текущей базы**:
    - если `MenuCalc.db` есть в AppData — используется он;
    - иначе пробует найти базу в каталоге приложения (для совместимости со старыми установками).
2. **Экспорт базы**:
    - `DatabaseBackupHelper.ExportDatabaseWithDialog()` копирует файл в папку резервных копий (обычно
      `Мои документы\PaymProd\Backups`);
    - после экспорта список бэкапов обновляется.
3. **Импорт базы**:
    - перед импортом текущая база сохраняется в резервную копию;
    - затем выбранный пользователем файл копируется на место текущей базы;
    - рекомендуется перезапустить приложение.
4. **Автоматическая резервная копия**:
    - `DatabaseBackupHelper.CreateAutoBackup()` создает бэкап с меткой времени.
5. **Восстановление из бэкапа**:
    - пользователь выбирает запись в гриде бэкапов (`BackupInfo`);
    - вызывается `LoadDatabaseFromFile(backup.FilePath)` с подтверждением.

### Резервные копии (`DatabaseBackupHelper`)

Класс `DatabaseBackupHelper` (в папке `Data`) инкапсулирует работу с бэкапами:

- каталог резервных копий — в `Мои документы\PaymProd\Backups`;
- поддерживает:
    - создание бэкапа из текущей базы;
    - загрузку списка (`GetAvailableBackups`);
    - восстановление базы из выбранного файла;
    - экспорт/импорт с помощью диалогов.

**Рекомендация:**  
Перед любыми массовыми изменениями (редактирование справочников, миграция и т.п.) создавать автокопию через
соответствующую кнопку.

### Загрузка стартовой базы (`UpdateService.TryDownloadStartDatabaseAsync`)

Используется:

- при первом запуске приложения (`App.OnStartup`);
- на странице `DatabaseManagerPage` (кнопка «Скачать стартовую базу»).

Логика:

1. Получает `UpdateInfo` с сервера (тот же JSON, что и для обновлений).
2. Ищет в нем URL файла стартовой базы (`StartDatabaseUrl` или аналогичное поле).
3. Скачивает файл во временный путь, затем копирует в переданный `targetPath`.
4. При `replaceExisting = true` предварительно делает резервную копию существующей базы.

Ошибки (нет доступа, нет сети и т.п.) показываются пользователю в виде диалогов «Ошибка при скачивании стартовой базы
данных».

### `UpdateDownloadWindow` — окно загрузки обновлений

Отображается при скачивании нового установщика приложения.

Функции:

- показывает заголовок (`SetTitle`) и версию (`SetVersion`);
- обновляет статус и прогресс (`UpdateProgress`):

```csharp
if (fraction.HasValue)
{
    DownloadProgressBar.IsIndeterminate = false;
    DownloadProgressBar.Value = Math.Clamp(fraction.Value * 100, 0, 100);
    DetailsTextBlock.Text = $"Скачано {FormatBytes(downloadedBytes)} из {FormatBytes(totalBytes)}";
}
else
{
    DownloadProgressBar.IsIndeterminate = true;
    DetailsTextBlock.Text = $"Скачано {FormatBytes(downloadedBytes)}";
}
```

Окно вызывается из `UpdateService` при подтверждении пользователем установки новой версии.

### Практические рекомендации

- **Всегда** хранить рабочие базы и бэкапы отдельно:
    - рабочая база — в `%LOCALAPPDATA%\PaymProdNet9\MenuCalc.db`;
    - бэкапы — в `Документы\PaymProd\Backups`.
- При ошибке «`unable to open database file`»:
    - убедиться, что у пользователя есть права на `%LOCALAPPDATA%`;
    - проверить, не заблокирован ли файл антивирусом;
    - при необходимости — скачать стартовую базу через `DatabaseManagerPage`.
