## Документация по PaymProdNet9

В папке `docs` находится подробная документация по всем основным формам, справочникам и отчетам приложения *
*PaymProdNet9**.

### 1. Общий обзор

- **[01_overview.md](01_overview.md)** — общее устройство приложения:
    - основная схема работы (меню → блюда → продукты → отчеты);
    - роли страниц и окон;
    - ключевые скрытые правила (округление, фасовка, авто‑добавление хозтоваров, расположение базы данных).

### 2. Меню и банкет

- **[02_menu_and_banquets.md](02_menu_and_banquets.md)** — формы работы с банкетами и меню:
    - `MainNavigationWindow` — главное окно навигации;
    - `CurrentMenuPage` — основная форма текущего меню;
    - `MenuPage` — старая форма меню (для совместимости);
    - `SavedMenusPage` — список сохраненных меню;
    - `SummaryTablePage` — сводная таблица по компонентам;
    - `PrintMenuPage` — отчет по меню (WPF + Word);
    - `MainWindow` / `ReportWindow` / `ReportPage` — старый интерфейс (описан как альтернативный).

### 3. Справочники продуктов и блюд

- **[03_products_and_dictionaries.md](03_products_and_dictionaries.md)** — все формы справочников:
    - `ProductsPage` — справочник продуктов, флаг `AutoAdd` и авто‑добавление хозтоваров в открытое меню;
    - `ProductPricesPage` — редактирование цен (общих и для конкретного меню);
    - `ProductTypesPage` — типы продуктов и флаг `HideInMenu`;
    - `MeasuresPage` — единицы измерения, фасовка и точность округления;
    - `DelicatesPage` — справочник блюд и их составов;
    - `DelicateTypesPage` — типы блюд;
    - `DictionariesPage` — комбинированный старый интерфейс для массовых правок.

### 4. Отчеты и печать

- **[04_reports.md](04_reports.md)** — все отчеты и связанные классы:
    - `SummaryTablePage` — сводные данные для Excel;
    - `ProductsReportPage` — современный отчет по товарам (WPF + Word), расчет цен по округленному количеству;
    - `ReportPage` / `ReportWindow` — старый отчет по товарам;
    - `PrintMenuPage` — отчет по меню;
    - `MenuPrinter` — генерация Word‑документов по меню и товарам.

### 5. База данных и обновления

- **[05_database_and_updates.md](05_database_and_updates.md)** — все, что связано с БД и обновлениями:
    - расположение и инициализация `MenuCalc.db` (только `%LOCALAPPDATA%`);
    - `DatabaseManagerPage` и `DatabaseManagerWindow` — резервное копирование, импорт/экспорт, загрузка стартовой базы;
    - `DatabaseBackupHelper` — формат и хранение бэкапов;
    - `UpdateService` и `UpdateDownloadWindow` — загрузка обновлений.

---

### Как пользоваться документацией

1. Если нужно понять **общую логику приложения** — начните с `01_overview.md`.
2. Если интересует **режим работы оператора** (создание банкетов, меню, печать) — см. `02_menu_and_banquets.md`.
3. Для вопросов по **справочникам и настройке единиц** — `03_products_and_dictionaries.md`.
4. Для анализа **отчетов и формул расчета** — `04_reports.md`.
5. Для администрирования **базы данных и обновлений** — `05_database_and_updates.md`.
