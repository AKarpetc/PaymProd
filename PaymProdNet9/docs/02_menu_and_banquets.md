## Формы меню и работы с банкетом

Этот документ описывает страницы и окна, которые относятся к созданию и редактированию меню банкета.

- `MainNavigationWindow` — главное окно навигации.
- `CurrentMenuPage` — основная форма работы с текущим меню (рекомендуемая).
- `MenuPage` — старая версия формы меню (оставлена для совместимости).
- `SavedMenusPage` — список сохраненных меню.
- `SummaryTablePage` — сводная таблица по продуктам для текущего меню.
- `PrintMenuPage` — WPF‑отчет по меню (печать / Word).
- `MainWindow` / `ReportWindow` / `ReportPage` — «старый» интерфейс (функционально повторяет новые страницы).

---

### `MainNavigationWindow` — главное навигационное окно

- Управляет навигацией между всеми страницами.
- Хранит активную кнопку навигации и подсвечивает ее.
- При загрузке:
  - показывает overlay «загрузка»;
  - по умолчанию переходит на `CurrentMenuPage`.
- Через метод `GetCurrentMenuData()` собирает данные текущего меню для:
  - сводной таблицы (`SummaryTablePage`);
  - отчета по товарам (`ProductsReportPage`);
  - отчета по меню (`PrintMenuPage`);
  - **если нет открытого меню** — показывает предупреждение и не открывает отчетные страницы.

**Неочевидный момент:**  
Если меню «закрыто» (`MenuRepository.CloseMenu`), все отчеты перестают работать, пока пользователь не откроет или не создаст новое меню.

---

### `CurrentMenuPage` — текущее меню (основная форма)

Основная форма для повседневной работы с банкетом.

#### Верхний блок «Информация о банкете»

- Поля:
  - **Название банкета** (`BanquetNameTextBox`)
  - **Количество человек** (`PeopleCountTextBox`) — только числа
  - **Дата, начало** (`BanquetDatePicker` — собственный `DateTimePicker` с датой и временем)
  - **Описание** (`DescriptionTextBox`)
- Кнопки:
  - **Перейти к заполнению / Начать меню** — создает новое меню (`MenuRepository.CreateMenu`), если:
    - заполнены `Название` и `Количество человек`;
    - нет уже открытого меню, иначе показывается предупреждение
      «Сначала закончите данное меню и нажмите 'Начать новое'!».
  - **Начать новое** — закрывает текущее меню (`CloseMenu`) и очищает форму.

**Скрытая логика:**

- поле даты/времени хранится в БД как `Menus.Dateban` (строка);
- при сохранении и загрузке дата приводится через `DateTime.Parse` и форматируется с временем;
- при генерации отчетов в `MainNavigationWindow` строка даты включается в `BanquetInfo[2]` и затем используется во всех отчетах.

#### Центральный блок — список позиций меню

- Таблица `MenuDelicatesDataGrid` показывает строки `MenuDel_act`:
  - блюдо, количество порций, стоимость, тип и др.;
  - при включенном фильтре «Показать товары» могут отображаться и «хозтовары».
- Загрузка меню (`LoadMenu`):
  - считывает открытое меню из `MenuRepository.GetOpenMenu()`;
  - подставляет шапку банкета;
  - загружает блюда меню через `GetMenuDelicates(menuId)`;
  - применяет фильтр `_showHiddenItems` через `UpdateMenuFilter()`.

**Важно:**  
Флаг `_showHiddenItems` не меняет данные в базе, только отображение. Логика фильтра завязана на признаках в `MenuDel_act` (например, хозтовары, авто‑добавленные продукты).

#### Правый/нижний блок — редактирование состава блюда

Когда пользователь выбирает блюдо и нажимает «Редактировать состав»:

- заполняются коллекции:
  - `_editingDelicateComponents` — компоненты выбранного блюда в текущем меню;
  - `_editingAvailableProducts` — список продуктов, которые можно добавить;
  - `_productLookup` и `_measureLookup` — кэши по продуктам и единицам для округления.
- перед сохранением вызывается `ApplyMenuRoundingInfo(components)`:
  - подставляет `component.Mera` и `component.FassIz` из справочника продукта (`ProductView.Ves` и `IzName`);
  - рассчитывает `MenuRoundingPrecision` на основании единицы измерения.

**Типичный скрытый сценарий:**

```csharp
if (_productLookup.TryGetValue(component.Prodid, out var product))
{
    if (!string.IsNullOrWhiteSpace(product.Ves))
        component.Mera = product.Ves;           // базовая мера из продукта

    if (string.IsNullOrWhiteSpace(component.FassIz) && !string.IsNullOrWhiteSpace(product.IzName))
        component.FassIz = product.IzName;     // мера фасовки из продукта
}
component.MenuRoundingPrecision = GetMenuPrecision(component.Mera);
```

Если у продукта в справочнике неправильно заполнены `Ves`/`IzName`, это напрямую влияет на то, как компонент отображается и округляется в отчете.

#### Левая панель — фильтр по типу и поиск блюда

- Кнопки типов блюд формируются динамически из `DelicateRepository.GetDelicateTypes()`:
  - дубликаты по названию удаляются (используется группировка по `Name`);
  - сортировка по `SortOrder`, затем по имени.
- Поиск:
  - строка `_currentSearchText` хранит текст запроса;
  - поиск выполняется только по названию (`Del`) и только по кнопке **Поиск** или нажатию Enter;
  - используется `_allAvailableDelicates` как полное множество вариантов, которое каждый раз фильтруется в `ApplyDelicateFilters`.

### `MenuPage` — старая форма работы с меню

- Логика почти полностью повторяет `CurrentMenuPage`, но:
  - использует более простой интерфейс (Grid + DataGrid + список доступных блюд);
  - отсутствует продвинутый режим редактирования состава прямо в меню;
  - нет фильтра «Показать товары»;
  - поиск по блюдам проще и выполняется без отдельной кнопки поиска.
- Оставлена для совместимости и может быть вызвана из `MainNavigationWindow` как альтернативный способ работы.

Рекомендуется использовать `CurrentMenuPage` как основную форму; `MenuPage` можно описывать в документации как «упрощенную/старую» версию.

---

### `SavedMenusPage` — список сохраненных меню

Функции:

- показывает все меню из `MenuRepository.GetAllMenus()` (включая закрытые);
- поиск по трем полям:
  - названию банкета (`Name`);
  - описанию (`Detail`);
  - дате (`DateBan`) — строковое сравнение, без парсинга.
- кнопки в каждой строке:
  - **Редактировать** — вызывает `MenuRepository.OpenMenu(menu.Id)` и переходит на `CurrentMenuPage` (через `NavigationService.Instance.NavigateTo<CurrentMenuPage>()`);
  - **Удалить** — подтверждение + `DeleteMenu(menu.Id)` + перезагрузка списка.

**Особенность:**  
После нажатия «Редактировать» текущее меню везде в приложении считается именно этим меню (все отчеты и «авто‑добавление» хозтоваров будут относиться к нему).

---

### `SummaryTablePage` — сводная таблица по текущему меню

Используется в основном для Excel‑экспорта.

- В `Page_Loaded` получает данные через свойства `MenuDelicates` и `BanquetInfo`, которые заполняет `MainNavigationWindow`.
- `GenerateSummaryData()`:
  - для каждого блюда `MenuDel_act` и его компонентов:
    - считает `totalWeight = component.Ves * delicate.Countpor`;
    - создает `DelicatesCollForSvod` с полями:
      - `Itog` — итог в натуральных единицах;
      - `ItogFass` — итог в фасовке (`totalWeight / Fass` при наличии фасовки).
- `ApplyReportRounding()`:
  - для `Itog` и `ItogFass` применяет точности округления из `Mera.RoundingPrecision`;
  - округление всегда **вверх**.
- Кнопка «Экспорт в Excel»:
  - сохраняет файл с именем `Сводная_таблица_<название>_<дата>.xlsx`;
  - заполняет шапку (банкет, кол-во гостей, дата, время) и строки по всем компонентам.

**Важно:**  
Эта страница не учитывает цены и не группирует данные — каждый компонент блюда сохраняется отдельной строкой.

---

### `PrintMenuPage` — отчет по меню

WPF‑страница для предварительного просмотра и сохранения отчета по меню.

- Свойства:
  - `Delicates` — список блюд (`DelicatesColl`) с заполненными `Lcomp`;
  - `BanquetInfo` — `[название, количество гостей, дата/время]`;
  - `MenuId` — идентификатор меню (используется при расчетах цены через `MenuPriceService`).

#### Кнопки

- **Отчет с ценами** — `GenerateReport(true)`:
  - строит документ с тремя колонками: «Блюдо», «Состав», «Цена, тг»;
  - цена блюда считается как сумма цен компонентов (через `MenuPriceService.GetComponentPriceInfo`).
- **Отчет без цен** — `GenerateReport(false)`:
  - две колонки: «Блюдо», «Состав»;
  - расчет цен не выполняется.
- **Сохранить в Word** — вызывает `MenuPrinter.PrintMenu` с теми же данными.

#### Особенности генерации документа

- Заголовок:

```csharp
var menuTitle = $"{BanquetInfo[0]} • {BanquetInfo[1]} человек • {BanquetInfo[2]}";
```

- Блюда группируются по типу (`Type` / `TypeSortOrder`);
- состав блюда формируется строками вида:

> «Продукт (кол-во единица) — цена»

где количество и единица считаются с учетом фасовки и правил округления, как в отчете по товарам.

---

### `MainWindow`, `ReportWindow`, `ReportPage` (старый интерфейс)

Эти формы повторяют логику:

- составления меню;
- формирования отчета по товарам (`ReportPage`);
- отображения отчета в отдельном окне (`ReportWindow`).

Они сохранены для пользователей старой версии и в новых сценариях, как правило, не используются, так как все основные функции перенесены в:

- `MainNavigationWindow` + `CurrentMenuPage` / `MenuPage`;
- `ProductsReportPage` / `SummaryTablePage` / `PrintMenuPage`.
