## 📖 Инструкция: Как создать новое блюдо

### Шаг 1: Откройте справочники

1. Запустите приложение
2. В главном меню выберите: **Справочники → Правка справочников**
3. Перейдите на вкладку **"Справочник блюд"**

### Шаг 2: Нажмите "Новое блюдо"

1. Внизу окна нажмите кнопку **"Новое блюдо"**
2. Панель редактирования станет активной ✅
3. Курсор автоматически установится в поле "Название"

### Шаг 3: Заполните данные

1. **Название:** Введите название блюда (обязательно)
2. **Тип:** Выберите тип из списка (обязательно)
    - Если нужного типа нет, создайте его через меню "Справочники → Типы блюд"
3. **Вес порции:** Укажите вес в граммах (опционально)
4. **Количество:** Укажите количество порций (по умолчанию 1)

### Шаг 4: Сохраните блюдо

1. Нажмите кнопку **"Сохранить блюдо"**
2. Появится сообщение: "Блюдо создано! Теперь можно добавить продукты в его состав."
3. Блюдо появится в списке блюд вверху

### Шаг 5: Добавьте продукты в состав (опционально)

1. После сохранения блюдо автоматически выбрано для редактирования
2. Слева выберите продукт из списка "Доступные продукты"
3. Нажмите кнопку **→** (стрелка вправо) чтобы добавить продукт
4. В таблице справа укажите **Вес** продукта в составе
5. Нажмите **"Сохранить блюдо"** еще раз для сохранения состава

### Шаг 6: Редактирование существующего блюда

1. Выберите блюдо из списка вверху (одним кликом)
2. Панель редактирования активируется автоматически
3. Измените нужные поля
4. Нажмите **"Сохранить блюдо"** для сохранения изменений

## ⚠️ Важные замечания:

### Обязательные поля:

- **Название блюда** - должно быть заполнено
- **Тип блюда** - должен быть выбран из списка

### Последовательность действий:

1. Сначала **создайте блюдо** (название + тип)
2. Нажмите "Сохранить блюдо"
3. Затем **добавьте продукты** в состав
4. Снова нажмите "Сохранить блюдо"

### Проверка перед началом работы:

Убедитесь, что заполнены справочники:

- ✅ **Типы блюд** (Холодные закуски, Горячие блюда, Десерты и т.д.)
- ✅ **Типы продуктов** (Овощи, Мясо, Рыба и т.д.)
- ✅ **Единицы измерения** (кг, л, шт и т.д.)
- ✅ **Продукты** с указанием типов и единиц измерения

Если справочники пустые, сначала заполните их через:

- Меню → Справочники → Типы блюд
- Меню → Справочники → Типы продуктов
- Меню → Справочники → Единицы измерения
