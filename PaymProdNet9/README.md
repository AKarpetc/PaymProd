# Система управления меню банкетов v2.0

Современное WPF приложение на .NET 9 для управления меню банкетов, ведения справочников блюд и продуктов, формирования отчетов.

## Основные возможности

- ✅ Создание и редактирование меню банкетов
- ✅ Управление справочниками блюд и продуктов
- ✅ Составление состава блюд из продуктов
- ✅ Автоматический расчет количества продуктов
- ✅ Формирование отчетов в Word (DOCX)
- ✅ Экспорт данных в Excel (XLSX)
- ✅ Печать меню и отчетов
- ✅ Современный Material Design интерфейс
- ✅ База данных SQLite (не требует установки SQL Server)

## Технологии

### Основной стек:
- **.NET 9** - последняя версия платформы .NET
- **WPF (Windows Presentation Foundation)** - для создания UI
- **Material Design In XAML** - современный дизайн интерфейса
- **SQLite** - легковесная встраиваемая база данных

### Используемые библиотеки (все бесплатные):
- `MaterialDesignThemes` (5.1.0) - Material Design компоненты для WPF
- `MaterialDesignColors` (3.1.0) - цветовая палитра Material Design
- `Microsoft.Data.Sqlite` (9.0.0) - работа с SQLite
- `System.Data.SQLite` (1.0.119) - дополнительная поддержка SQLite
- `DocumentFormat.OpenXml` (3.1.1) - официальная библиотека Microsoft для создания документов Word без MS Office
- `ClosedXML` (0.104.2) - создание Excel файлов без MS Office

## Системные требования

- **ОС**: Windows 10/11 (x64)
- **.NET Runtime**: .NET 9.0 Runtime или SDK
- **Память**: минимум 512 МБ RAM

## Установка и запуск

### Вариант 1: Запуск из исходного кода

1. Установите [.NET 9 SDK](https://dotnet.microsoft.com/download/dotnet/9.0)

2. Клонируйте или распакуйте проект

3. Откройте терминал в папке `PaymProdNet9`

4. Восстановите зависимости:
```bash
dotnet restore
```

5. Запустите приложение:
```bash
dotnet run
```

### Вариант 2: Сборка исполняемого файла

1. Соберите проект:
```bash
dotnet publish -c Release -r win-x64 --self-contained false
```

2. Исполняемый файл будет в папке:
```
bin\Release\net9.0-windows\win-x64\publish\
```

### Вариант 3: Самодостаточная сборка (не требует .NET на ПК)

```bash
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true
```

## Использование

### Создание нового меню:

1. Заполните поля: название банкета, количество гостей, дату, описание
2. Нажмите кнопку "Перейти к заполнению" (зеленая кнопка play)
3. Выберите блюда из списка внизу (двойной клик для добавления)
4. Укажите количество порций для каждого блюда
5. Нажмите "Сохранить изменения в меню"

### Работа со справочниками:

1. Откройте меню "Справочники" → "Правка справочников"
2. Вкладка "Справочник блюд": создавайте блюда и добавляйте в них продукты
3. Вкладка "Справочник продуктов": добавляйте новые продукты с типами и мерами

### Формирование отчетов:

1. Создайте и заполните меню
2. Нажмите "Отчет" в главном меню
3. Выберите формат: Word, Excel или печать
4. Просмотрите сводную таблицу с расчетами

## Миграция данных из старой версии

Для миграции данных из старой версии (SQL Server CE) в новую (SQLite):

1. Экспортируйте данные из старой базы в SQL скрипты
2. Адаптируйте синтаксис для SQLite
3. Импортируйте данные в новую базу

*Примечание: Инструмент автоматической миграции находится в разработке*

## Устранение неполадок

### Приложение не запускается:
- Убедитесь, что установлен .NET 9 Runtime
- Проверьте, что все файлы в папке приложения не повреждены

### Ошибки при сохранении:
- Проверьте права доступа к папке с базой данных
- Убедитесь, что файл `MenuCalc.db` не открыт в другой программе

### Ошибки при создании отчетов:
- Для Word: убедитесь, что доступно место на диске
- Для Excel: проверьте права на запись в выбранную папку
