## 🚀 Запуск приложения

### Способ 1: Через .NET CLI (рекомендуется для разработки)

```powershell
cd PaymProdNet9
dotnet run
```

### Способ 2: Через батник

Просто запустите файл:

```
run.bat
```

### Способ 3: Сборка исполняемого файла

```powershell
# Вариант А: Требует .NET 9 Runtime на целевом ПК
dotnet publish -c Release -r win-x64 --self-contained false

# Вариант Б: Автономная сборка (не требует .NET на ПК)
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true
```

Готовый exe-файл будет в папке:

```
bin\Release\net9.0-windows\win-x64\publish\PaymProdNet9.exe
```

## 📋 Что было исправлено

### 1. Замена библиотеки для Word документов

- **Было:** Docx 5.0.0 (несовместимый API)
- **Стало:** DocumentFormat.OpenXml 3.1.1 (официальная библиотека Microsoft)
- **Результат:** Полная поддержка создания .docx файлов

### 2. Исправление конфликта версий

- Обновлена версия DocumentFormat.OpenXml до 3.1.1
- Устранен конфликт с зависимостью ClosedXML

### 3. Добавление недостающих using директив

- Добавлен `using System.Windows.Controls;` для PrintDialog

### 4. Исправление предупреждений о nullable

- Улучшена обработка null-ссылок в коде
- Разделены проверки на null для ясности

## 📁 Структура базы данных

При первом запуске автоматически создается SQLite база данных:

```
C:\Users\<Пользователь>\AppData\Local\PaymProdNet9\MenuCalc.db
```

База содержит таблицы:

- `Menus` - Меню банкетов
- `MenuDelicates` - Связь меню и блюд
- `Delicates` - Справочник блюд
- `DelicateComponents` - Состав блюд
- `Products` - Справочник продуктов
- `ProductTypes` - Типы продуктов
- `MeasureTypes` - Единицы измерения

## 📝 Основные функции

### 1. Создание меню

1. Заполните информацию о банкете (название, количество гостей, дата)
2. Нажмите "Перейти к заполнению" (кнопка Play)
3. Добавьте блюда двойным кликом
4. Укажите количество порций
5. Сохраните изменения

### 2. Управление справочниками

1. Меню → Справочники → Правка справочников
2. Вкладка "Блюда" - создание и редактирование блюд
3. Вкладка "Продукты" - управление продуктами
4. Добавляйте продукты в состав блюд

### 3. Формирование отчетов

1. Создайте и заполните меню
2. Меню → Отчет
3. Выберите формат:
    - 💾 Сохранить в Word
    - 📊 Экспорт в Excel
    - 🖨️ Печать

При первом запуске база данных создается пустой. Рекомендуется:

## 🐛 Возможные проблемы

### Приложение не запускается

**Решение:** Установите [.NET 9 Runtime](https://dotnet.microsoft.com/download/dotnet/9.0)

### Ошибка "не найден файл SQLite.Interop.dll"

**Решение:** Пересоберите проект: `dotnet clean && dotnet build`

### Не создаются Word документы

**Решение:** Проверьте права доступа к папке временных файлов
