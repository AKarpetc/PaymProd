# Настройка автоматической загрузки на Google Drive

## Быстрая настройка (5 минут)

### Вариант 1: Через OAuth Playground (Рекомендуется)

1. Откройте приложение и перейдите в **"Управление БД"**
2. Нажмите кнопку **"⚙️ Настроить автозагрузку"**
3. Нажмите **"🔗 Открыть ссылку для получения токена"**
4. В открывшемся браузере:
   - В левой панели найдите **"Drive API v3"**
   - Выберите **"https://www.googleapis.com/auth/drive.file"**
   - Нажмите **"Authorize APIs"**
   - Войдите в свой Google аккаунт
   - Разрешите доступ
   - Нажмите **"Exchange authorization code for tokens"**
   - Скопируйте **"Access token"** из правой панели
5. Вставьте токен в поле в приложении
6. Нажмите **"Сохранить токен"**

Готово! Теперь загрузка будет автоматической.

### Вариант 2: Через Google Cloud Console (Для продвинутых)

1. Создайте проект в [Google Cloud Console](https://console.cloud.google.com/)
2. Включите **Google Drive API**
3. Создайте **OAuth 2.0 Client ID**
4. Используйте OAuth Playground для получения токена (см. Вариант 1)

## Как это работает

- **С токеном**: Файл автоматически загружается на Google Drive через API
- **Без токена**: Открывается браузер для ручной загрузки

## Безопасность

- Токен сохраняется локально в папке `%LocalAppData%\PaymProdNet9\`
- Токен используется только для загрузки файлов в указанную папку
- Токен можно удалить в любой момент (просто удалите файл `google_drive_token.txt`)

## Примечания

- Токен действителен ограниченное время (обычно 1 час)
- Для постоянной работы можно настроить refresh token (требует дополнительной настройки)
- Или просто обновляйте токен периодически через OAuth Playground
