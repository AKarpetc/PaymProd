# Загрузка базы данных на Google Drive

## Описание

Приложение поддерживает загрузку базы данных на Google Drive для резервного копирования и обмена данными.

## Как использовать

1. Откройте страницу **"Управление БД"** в меню приложения
2. Нажмите кнопку **"☁️ Поделиться БД (Google Drive)"**
3. Следуйте инструкциям:
   - Файл базы данных будет скопирован во временную папку
   - Откроется проводник Windows с выделенным файлом
   - Откроется браузер с папкой Google Drive
   - Перетащите файл из проводника в браузер или используйте кнопку "Создать" → "Загрузить файлы"

## Папка на Google Drive

Файлы загружаются в папку:
**https://drive.google.com/drive/folders/1m6KPyu7bTWK6EXOxOUrYK9vYbRAJmrZO**

## Автоматическая загрузка через API (опционально)

Для автоматической загрузки без ручного перетаскивания можно настроить Google Drive API:

1. Создайте проект в [Google Cloud Console](https://console.cloud.google.com/)
2. Включите Google Drive API
3. Создайте OAuth 2.0 credentials
4. Используйте метод `UploadDatabaseToGoogleDriveApiAsync` с access token

## Примечания

- Файл базы данных копируется во временную папку с понятным именем
- Имя файла включает дату и время: `PaymProdNet9_DB_YYYYMMDD_HHMMSS.db`
- Временный файл можно удалить после загрузки
