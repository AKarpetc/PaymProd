## 📊 **Функциональность:**

### **Режим просмотра списка:**

| Действие | Описание |
|----------|----------|
| **Кнопка "Создать"** | Большая зеленая кнопка вверху переключает в режим создания |
| **Кнопка ✏️ (редактировать)** | Открывает блюдо для редактирования |
| **Кнопка 🗑️ (удалить)** | Удаляет блюдо с подтверждением |
| **Сортировка** | Новые блюда автоматически ВВЕРХУ списка |

### **Режим создания/редактирования:**

| Поле/Кнопка | Описание |
|-------------|----------|
| **Название** | Обязательное поле, текст |
| **Тип** | Обязательное поле, выбор из справочника |
| **Вес порции** | Опционально, число (граммы) |
| **Количество порций** | Опционально, число (по умолчанию 1) |
| **Состав блюда** | Добавление продуктов с указанием веса |
| **Кнопка "Отмена"** | Возврат к списку без сохранения |
| **Кнопка "Создать/Сохранить"** | Сохранение блюда и возврат к списку |

## 🚀 **Как использовать:**

### **Создание нового блюда:**

1. **Откройте справочник блюд:**
   - Кликните **🍽️ Блюда** в сайдбаре

2. **Нажмите "Создать новое блюдо":**
   - Большая зеленая кнопка вверху
   - Откроется форма создания

3. **Заполните информацию:**
   ```
   Название: "Салат Цезарь"
   Тип: [▼ Салаты]
   Вес: 250 г
   Количество: 50 порций
   ```

4. **Добавьте состав (опционально):**
   - Найдите продукт в левом списке
   - Нажмите кнопку **→**
   - Укажите вес продукта в таблице справа

5. **Сохраните блюдо:**
   - Нажмите **💾 Создать блюдо**
   - Вернетесь к списку
   - **Новое блюдо появится ВВЕРХУ списка!**

### **Редактирование существующего блюда:**

1. **В списке блюд найдите нужное блюдо**

2. **Нажмите кнопку ✏️ (редактировать)**
   - Откроется форма редактирования
   - Заголовок: "Редактирование блюда"
   - Все поля заполнены текущими значениями

3. **Измените нужные поля**

4. **Сохраните изменения:**
   - Нажмите **💾 Сохранить изменения**
   - Вернетесь к списку

### **Отмена создания/редактирования:**

1. **В форме создания/редактирования**

2. **Нажмите ❌ Отмена**
   - Появится подтверждение
   - Изменения не сохранятся
   - Вернетесь к списку блюд

### **Удаление блюда:**

1. **В списке блюд найдите блюдо**

2. **Нажмите кнопку 🗑️ (удалить)**
   - Появится подтверждение
   - После подтверждения блюдо удалится

## ⚡ **Преимущества новой структуры:**

### ✅ **Разделение режимов**
- **Просмотр:** Весь экран для таблицы блюд
- **Редактирование:** Весь экран для формы
- **Не мешают друг другу**

### ✅ **Интуитивный интерфейс**
- Понятно где создавать (большая зеленая кнопка)
- Понятно где редактировать (кнопка ✏️ у каждого блюда)
- Понятно как отменить (кнопка "Отмена")

### ✅ **Экономия места**
- Форма не занимает место когда не нужна
- Таблица использует весь экран

### ✅ **Новые блюда вверху**
- Только что созданное блюдо сразу видно
- Не нужно скроллить вниз
- Удобно проверить что создалось

### ✅ **Валидация**
- Проверка обязательных полей
- Сообщения об ошибках
- Фокус на проблемном поле

### **Методы переключения режимов:**

```csharp
private void ShowListView()
{
    ListViewPanel.Visibility = Visibility.Visible;
    EditViewPanel.Visibility = Visibility.Collapsed;
}

private void ShowEditView(bool isEdit)
{
    _isEditMode = isEdit;
    
    ListViewPanel.Visibility = Visibility.Collapsed;
    EditViewPanel.Visibility = Visibility.Visible;
    
    if (isEdit)
    {
        EditPanelTitle.Text = "Редактирование блюда";
        SaveButton.Content = "💾 Сохранить изменения";
    }
    else
    {
        EditPanelTitle.Text = "Создание нового блюда";
        SaveButton.Content = "💾 Создать блюдо";
    }
}
```
